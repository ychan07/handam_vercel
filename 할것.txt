일기 요약 
 - OCR을 통한 일기에서 글자 추출하기
 - 추출된 글자 요약 

  - 추출된 글자 어디에 저장?
   - 개인 디바이스 vs 서버 DB (관계형 or 비관)
    - 일기 특성상 많은 데이터가 발생하므로 디바이스 저장이 나을수도
 - 정규화 할지 한다면 얼마나?
  -성능이 낮은 OCR모델을 사용한다면 필수
  -클로바 정도면 괜찮, 오타 나더라도 LLM선에서 커버 가능 
 - OCR 뭐 쓸거?
  -naver clova (free)


AI api는 gemini(비용 절감)
 - 사용자에게 요금제를 제시하고 ai를 선택하게 할 수 있음
 - 비용문제가 생긴다면 gemini외에 deepseek, claude haiku등 저렴한 모델 사용 고려

시스템 프롬프트
 - 일기 요약 전문가 페르소나
 - 사용자 설정에 대비해서 프롬프트 다양화
사용자 설정
 - 사용자가 일기를 요약할 모델의 정확도 선택(요금제에 따라 다름)
  - 모델명을 바로 적어놓으면 UX저하, 모델명은 별도로 확인할 사람만 확인할 수 있게, 선택창에서는 성능 상,중,하 등으로 표기 
 - 모델의 성향 설정 따듯함,기계적임 등 모델의 공감력 정도 설정 


 
처리 파이프라인
 1. 사용자가 일기 사진 입력
 2. OCR과 정규화 과정을 통해 텍스트 형태로 추출
 3. LLM api를 통해 요약 및 요약된 데이터 저장
